# AI Code Reviewer 🤖

AI-powered code review tool built with **React** and **Node.js**, using **Google Gemini AI** to analyze code, detect issues, and suggest improvements.
Code snippets are displayed with **syntax highlighting** for clarity.

---

## Features ✨

- AI-generated structured code reviews  
- Sections include:
  - ❌ Bad Code
  - 🔍 Issues
  - ✅ Recommended Fix
  - 💡 Improvements  
- Syntax-highlighted code blocks  
- Supports multiple programming languages  

---

## Tech Stack 🛠️

- Frontend:  React, PrismJS / Highlight.js  
- Backend:  Node.js, Express  
- AI:  Google Gemini AI (gemini-2.5-flash)  
- Styling:  CSS
